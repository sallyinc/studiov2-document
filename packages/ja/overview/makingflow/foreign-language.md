# 外国語版ウズへの作品提出

2024年12月より、繫体字または韓国語の読み書きができる制作者がその言語で制作した作品、日本語で既にリリースされている作品を翻訳した作品などの提出が可能になりました。

## 条件

* 日本語版が既にウズスタジオにある作品の場合は[エディション機能](../../scenariohome/edition.md)を使って翻訳版を追加すること
* AIによる翻訳を利用してもよいが、必ず繁体字または韓国語ネイティブの方によるチェック・校正もおこなってから提出すること
* 画像等も全て翻訳を行い、日本語が作中にない状態にすること
* 無料作品・有料作品にかかわらず、ネイティブの方によるテストプレイを必ず1回以上おこなうこと
* ウズスタジオ内の[作家プロフィールの編集](../../top/profile.md)から、繫体字または韓国語用の作家名を追加しておくこと

{% hint style="info" %}
シナリオのコピーの作成方法

1. ウズスタジオのシナリオ一覧で該当シナリオの「・・・」をクリックします。
2. 「エディションを追加」をクリックします。（※「複製する」を選ぶとエディション外に作成されてしまいます）
3. ページが切り替わったら「関連エディションを作成」をクリックします。
4. 「コピーから作成」をクリックします。（※このとき、コピー対象になるのは一番上に並んでいるエディションです）
{% endhint %}

{% hint style="info" %}
翻訳者の追加方法

1. ウズスタジオのシナリオ一覧で該当シナリオの「・・・」をクリックします。
2. 「エディションを追加」をクリックします。
3. ページが切り替わったら「メンバーと取り分」をクリックします。
4. 「制作メンバーを追加」をクリックし、翻訳者のウズユーザーIDを入力してください。権限は少なくとも「シナリオ内容の編集可」が必要です。
{% endhint %}

## 提出方法

日本語での提出と同様です。同じ審査フォームまたは各言語の審査フォーム\*からご提出ください。 審査はネイティブの方が行います（校正は審査対応範囲外です）。

{% hint style="info" %}
\*各言語の審査フォームへのアクセス方法\
「https://studio.uzu-app.com/ja」の末尾を「繁体字：zh-TW」「韓国語：ko」に変更すると、ウズスタジオ上のDiscord遷移ボタンが各言語用に変わります。その状態でシナリオの「リリース管理」画面を開くと、各言語の審査フォームにアクセスできます。
{% endhint %}

## 返却について

審査返却は各言語のDiscordサーバーにて行われます。

「https://studio.uzu-app.com/ja」の末尾を「繁体字：zh-TW」「韓国語：ko」に変更すると、ウズスタジオ上のDiscord遷移ボタンが各言語用に変わります。そこから入室をお願いいたします。



## Q\&A

Q: 台湾版・韓国語版のウズスタジオは日本版のウズスタジオとは別ですか？\
A: 同じです。シナリオ概要編集ページで「言語」を「中国語(繁体字)」「韓国語」にするだけでOKです。

Q: テストプレイにおける作者観戦は必須ですか？\
A: 必須ではありません。言語が分かる方は観戦をオススメします。分からない方は校正担当者にお願いしてみましょう。

Q: 有料作品の場合、プレイ料金は日本と同じになりますか？\
A: 自由に設定可能です。
