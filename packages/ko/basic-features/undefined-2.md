# 화면 디자인

2025년 12월부터 배경 이미지·컬러 테마 편집 화면을 새로운 모드로 전환할 수 있게 되었습니다.

### 화면 디자인 모드로 전환하기 <a href="#dezainmdohenorie" id="dezainmdohenorie"></a>

예전 모드의 배경 이미지·컬러 테마 편집 화면이 적용된 시나리오에서는 아래와 같은 안내가 나타납니다↓

<img src="../.gitbook/assets/01 (63).png" alt="" width="563">

「자세히 보기」를 누르면 화면 디자인 모드로 전환할 수 있습니다. 다만 **지금까지의 설정은 모두 초기화**되니 주의해 주세요.

<img src="../.gitbook/assets/02 (50).png" alt="" width="491">

### 화면 디자인 사용 방법 <a href="#dezainnoi" id="dezainnoi"></a>

화면 디자인에서는 폰트·아이콘·컬러 테마·배경 이미지를 자유롭게 조합해 사용할 수 있습니다.\
예를 들어 Noto Sans JP는 고딕체 폰트이고, 스트롱은 검게 칠한 모양이 기본인 아이콘입니다.

<img src="../.gitbook/assets/03 (41).png" alt="" width="563">

특정 단계나 특정 조건에서 다른 디자인의 화면을 표시하고 싶을 때는 「조건부 스타일 추가」를 선택합니다.

추가한 스타일의 페인트 마크를 누르면 스타일을 자세히 설정할 수 있습니다.

<img src="../.gitbook/assets/04 (32).png" alt="" width="563">

조건부 스타일이 더 이상 필요 없을 때는 「・・・」 버튼에서 삭제할 수 있습니다.
