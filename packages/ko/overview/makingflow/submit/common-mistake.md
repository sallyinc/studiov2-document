# 문장에서 자주 지적되는 사항

## 문장에서 자주 지적되는 사항

상세 심사에서는 표준 맞춤법과 일반적인 문장 규칙을 기준으로 오탈자와 표현을 확인합니다.

시나리오를 만드는 단계(심사 제출 전)부터 아래 내용을 의식해 두면 재제출이나 심사 후 수정을 줄일 수 있습니다. 헷갈리는 표현은 국립국어원 「[표준국어대사전](https://stdict.korean.go.kr/)」이나 맞춤법 검사기로 확인해 보세요.

### 맞춤법

**① 자주 틀리는 표현**

* 되/돼: 「안 되요」 → 「안 돼요」(「되어」로 바꿔 말이 되면 「돼」)
* 안/않: 「않 가다」 → 「안 가다」, 「가지 안다」 → 「가지 않다」
* 몇일 → 며칠
* 금새 → 금세
* 왠일 → 웬일 (「왠지」는 맞는 표현)
* 어떻해 → 어떡해 / 어떻게
* 로서/로써: 자격은 「로서」(탐정으로서), 수단은 「로써」(대화로써)
* 결제/결재: 돈을 낼 때는 「결제」, 서류를 승인할 때는 「결재」

**② 띄어쓰기**

* 의존 명사는 띄어 씁니다: 할 **수** 있다, 먹은 **것**, 그럴 **때**, 갈 **데**
* 「\~하다」, 「\~되다」가 붙는 말은 붙여 씁니다: 조사하다, 발견되다
* 숫자와 단위는 띄어 쓰는 것이 원칙이지만, 아라비아 숫자 뒤에서는 붙여 써도 됩니다: 3 층 / 3층. 작품 안에서 통일해 주세요.

### 문장 부호

**① 말줄임표**

「……」(가운데 6점) 또는 「...」(아래 3점) 중 하나로 통일해 주세요. 「..」, 「....」처럼 점의 개수가 제각각인 경우가 자주 보입니다.

**② 물음표·느낌표**

문장 중간에서 물음표(?)나 느낌표(!)로 문장을 끝낸 뒤 다음 문장이 이어진다면, 뒤에 한 칸 띄어 주세요.

**③ 따옴표**

대사와 인용에 쓰는 따옴표(“ ”, ‘ ’, 「 」 등)를 작품 전체에서 하나로 통일해 주세요. 일본어 원작을 번역한 경우 「」와 “ ”가 섞이는 일이 많습니다.

**④ 쉼표·마침표**

쉼표가 없어 읽기 어려운 긴 문장이나, 마침표가 빠진 문장이 자주 보입니다. 제출 전에 한 번 확인해 주세요.

### 기타

**① 들여쓰기와 줄바꿈**

캐릭터 텍스트 등에서 문단 첫머리 들여쓰기 여부나, 문단 사이 빈 줄 개수가 통일되지 않은 경우가 자주 보입니다. 휴대폰 화면에서 읽기 편하도록 짧은 문단으로 나누고, 작품 전체에서 같은 규칙을 지켜 주세요.

**② 표기 흔들림**

같은 말이 여러 방식으로 적혀 있는 경우가 자주 보입니다. 제출 전에 한 번 확인해 주세요.

* 외래어: 메세지 / 메시지(O), 컨텐츠 / 콘텐츠(O), 스마트폰 / 스마트 폰
* 숫자: 1층 / 일층, 3명 / 세 명
* 이름: 캐릭터 이름이나 지명의 표기가 텍스트마다 다르지 않은지

**③ 말투**

캐릭터별 말투(존댓말·반말, 1인칭 「나/저」 등)와 안내문의 문체(「\~합니다」/「\~해요」)가 텍스트마다 바뀌지 않는지 확인해 주세요.

**④ 번역투 표현**

일본어 원작을 번역했거나 일본어 자료를 참고한 경우, 우리말로 어색한 표현이 남기 쉽습니다.

* \~에 있어서 → \~에서
* \~되어지다(이중 피동) → \~되다
* \~하는 것이 가능하다 → \~할 수 있다
* \~적(的)인 표현의 반복 → 꼭 필요한 곳에만
