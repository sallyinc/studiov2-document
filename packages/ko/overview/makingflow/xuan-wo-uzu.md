# 외국어판 우즈에 작품 제출하기

2024년 12월부터 번체자 또는 일본어를 읽고 쓸 수 있는 제작자가 해당 언어로 제작한 작품, 한국어로 이미 릴리스된 작품을 번역한 작품 등을 제출할 수 있게 되었습니다.

## 조건

* 한국어판이 이미 우즈 스튜디오에 있는 작품이라면 [에디션 기능](../../scenariohome/edition.md)을 사용해 번역판을 추가할 것
* AI 번역을 이용해도 되지만, 반드시 번체자 또는 일본어 원어민의 확인·검수를 거친 뒤 제출할 것
* 이미지 등도 모두 번역해, 작품 안에 한국어가 남아 있지 않은 상태로 만들 것
* 무료 작품·유료 작품과 관계없이, 원어민이 참여하는 테스트 플레이를 반드시 1회 이상 진행할 것
* 우즈 스튜디오 안의 [작가 프로필 편집](../../top/profile.md)에서 번체자 또는 일본어용 작가명을 추가해 둘 것

{% hint style="info" %}
**시나리오 복사본 만드는 방법**

1. 우즈 스튜디오의 시나리오 목록에서 해당 시나리오의 「・・・」를 클릭합니다.
2. 「에디션 추가」를 클릭합니다. (※「복제하기」를 선택하면 에디션 밖에 별도 시나리오로 만들어집니다)
3. 페이지가 바뀌면 「관련 에디션 생성」을 클릭합니다.
4. 「복사에서 생성」을 클릭합니다. (※이때 복사되는 것은 맨 위에 있는 에디션입니다)
{% endhint %}

{% hint style="info" %}
**번역자 추가 방법**

1. 우즈 스튜디오의 시나리오 목록에서 해당 시나리오의 「・・・」를 클릭합니다.
2. 「에디션 추가」를 클릭합니다.
3. 페이지가 바뀌면 「멤버와 분배」를 클릭합니다.
4. 「제작 멤버 추가」를 클릭하고 번역자의 우즈 사용자 ID를 입력해 주세요. 권한은 최소한 「시나리오 내용 편집 가능」이 필요합니다.
{% endhint %}

## 제출 방법

한국어로 제출할 때와 동일합니다. 같은 심사 폼으로 제출해 주세요. 심사는 원어민이 진행합니다(검수는 심사 대응 범위에 포함되지 않습니다).

{% hint style="info" %}
**\*각 언어용 심사 폼으로 들어가는 방법**

「https://studio.uzu-app.com/ko」의 끝부분을 「ja」(번체자는 「zh-TW」)로 바꿔 「https://studio.uzu-app.com/ja」로 접속하면, 우즈 스튜디오의 Discord 이동 버튼이 해당 언어용으로 바뀝니다. 이 상태에서 시나리오의 「릴리스 관리」 화면을 열면 한국어 심사 폼으로 들어갈 수 있습니다.
{% endhint %}

## Q\&A

Q: 대만판·일본판 우즈 스튜디오는 한국판 우즈 스튜디오와 별개인가요?\
A: 같습니다. 시나리오 개요 편집 페이지에서 「언어」를 「중국어(번체)」 또는 「일본어」로 설정하기만 하면 됩니다.

Q: 테스트 플레이에서 작가 관전은 필수인가요?\
A: 필수는 아닙니다. 해당 언어를 아는 분은 관전을 추천합니다. 모르는 분은 검수 담당자에게 부탁해 보세요.

Q: 유료 작품의 경우, 플레이 요금은 한국과 동일해지나요?\
A: 자유롭게 설정할 수 있습니다.
